# Gala — Travel Social Prototype

GitHub-ready static prototype for a travel-focused social network.

## Current prototype
- Social travel feed
- Explore destinations and categories
- Map discovery
- Groups and saved trips
- Profile
- Create post modal
- **Trip Journey:** share a complete trip with route, multiple stops, transport modes, photos/videos, distance and moving time
- Universal travel modes: ✈️ airplane, 🚢 ferry/boat, 🚌 bus, 🚗 car, 🏍️ motorcycle, 🚶 walking, 🥾 hiking, and more
- Responsive mobile layout

## Run locally
Open `index.html`, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
Upload the repository to GitHub and enable **Settings → Pages → Deploy from branch** using the root folder.

## Next production architecture
The prototype is frontend-only. A production version can use Flutter, Node/NestJS, PostgreSQL/PostGIS, object storage, authentication, maps, search, notifications, groups/events, reviews, business verification, and real GPS journey tracking.
